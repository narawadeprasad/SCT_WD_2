# SCT_WD_2
This task involves creating a responsive web page using modern CSS techniques. It focuses on layout design, responsiveness, and improving user experience across devices.

index.html

Provides the layout for the stopwatch application.

Contains display elements for time and control buttons.

Connects the stylesheet and JavaScript logic files.

style.css

Styles the stopwatch interface with a clean and minimal UI.

Uses layout techniques to center elements and improve readability.

Ensures responsiveness across different screen sizes.

script.js

Implements stopwatch functionality including start, pause, reset, and lap features.

Handles time calculation using JavaScript timing functions.

Dynamically updates the display and lap list.
