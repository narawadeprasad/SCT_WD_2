# SCT_WD_2

Stopwatch Web Application


Project Files Description

📄 index.html

•This file serves as the main structure of the stopwatch application.

•It contains the display area to show time in minutes, seconds, and milliseconds.

•Includes control buttons such as Start, Pause, Lap, and Reset.

•Links the external CSS file for styling and the JavaScript file for stopwatch functionality.

🎨 style.css

•Responsible for the visual styling of the stopwatch application.

•Designs a clean and user-friendly interface with proper alignment.

•Uses CSS properties to style buttons, display text, and layout.

•Ensures the application is responsive and works well on different screen sizes.

⚙️ script.js

•Handles all the logic and interactivity of the stopwatch.

•Implements core functionalities such as start, pause, resume, lap recording, and reset.

•Uses JavaScript timing functions to calculate elapsed time accurately.

•Dynamically updates the display and lap list without refreshing the page.

🛠️ Technologies Used

•HTML5 – Structure of the application

•CSS3 – Styling and layout

•JavaScript – Stopwatch logic and interactivity

🎯 Learning Outcomes

•Understanding of JavaScript time functions and intervals

•Hands-on experience with event handling

•Improved DOM manipulation skills

Ability to build an interactive web application from scratch
